Windover for macOS

Getting started

  • Pin a region: click the Windover icon in the menu bar, then drag to select an area. Press Esc to cancel.
  • Move: drag the floating window. Resize: pinch, Option-scroll, or ⌘+ / ⌘−. ⌘0 restores actual size.
  • Save or close: move the pointer near the window's top-right corner to reveal the buttons, or use ⌘S / ⌘W. Double-click or Esc also closes it.
  • More options: right-click the window for Copy, Opacity and more; right-click the menu bar icon for Close All Pins and Quit.

Captures only show the desktop wallpaper
